# LC 15. 3Sum (Medium) · Two Pointers

> 找出所有满足 `nums[i] + nums[j] + nums[k] == 0` 且 `i != j != k` 的三元组，不能有重复 triplet。

**Pattern**: Skip-Duplicates Two-Pointer  
**Date**: 2026/05/21 (Day 47)

---

## 🎯 核心思路：Sort + 固定 i + 双指针扫 (l, r)

1. **Sort** array → 让相同值相邻 + 让 sum 大小有方向性
2. **固定 i**，在剩余范围 `[i+1, len-1]` 用 two-pointer 找 `nums[l] + nums[r] == -nums[i]`
3. 找到 → 跳过 duplicates；和太大 → `r--`；和太小 → `l++`

---

## 💻 Code (Optimal: O(n²) time, O(1) space)

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        res = []
        nums.sort()
        
        for i, a in enumerate(nums):
            # Skip duplicate i (跳过重复的 fixed value)
            if i > 0 and a == nums[i - 1]:
                continue
            
            l, r = i + 1, len(nums) - 1
            while l < r:
                s = a + nums[l] + nums[r]
                if s > 0:
                    r -= 1
                elif s < 0:
                    l += 1
                else:
                    res.append([a, nums[l], nums[r]])
                    l += 1
                    # Skip duplicate l —— l < r 放前面，short-circuit 防 IndexError
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1
        return res
```

---

## 🔑 Key Insight: Skip-Duplicates Pattern

> Sorted array → duplicate values 一定**相邻** → skip 时只需检查 `nums[x] == nums[x-1]`

**3 个 skip point**：

| 位置 | Code | 作用 |
|---|---|---|
| **Outer i** | `if i > 0 and a == nums[i-1]: continue` | 跳过重复的 fixed 值 |
| **Inner l** | `while l < r and nums[l] == nums[l-1]: l += 1` | 找到匹配后跳过重复 l |
| **r (隐式)** | —— | l 跳过 dup 后，r 不会重新产生同 triplet |

### ⚠️ 为什么 `l < r` 放前面

```python
while l < r and nums[l] == nums[l - 1]:  # ✅ safe
while nums[l] == nums[l - 1] and l < r:  # ⚠️ 潜在 IndexError
```

Python `and` 短路求值 —— 左边 False 不评估右边。**把 boundary check 放前面是 senior 习惯**，面试 code review 会被注意。

---

## ❌ 失败 case 验证（无 skip 时）

输入：`[-2, -2, 0, 0, 2, 2]`

```
i=0, a=-2, l=1, r=5
  l=2, r=5: -2 + 0 + 2 = 0 ✓ → res=[[-2,0,2]], l++
  l=3, r=5: -2 + 0 + 2 = 0 ✓ → res=[[-2,0,2], [-2,0,2]]  ❌ 重复!
```

**加 skip 后**：`l=2` 找到 → `l=3`，`nums[3]==nums[2]` → `l=4` → 退出 ✅

## 🚫 Alternative: Set 去重（suboptimal，但要知道）

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        seen = set()
        for i in range(len(nums)):
            l, r = i + 1, len(nums) - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s > 0: r -= 1
                elif s < 0: l += 1
                else:
                    seen.add((nums[i], nums[l], nums[r]))
                    l += 1
                    r -= 1
        return [list(t) for t in seen]
```

### 为什么更差

| 维度 | Skip 版 | Set 版 |
|---|---|---|
| Time 渐近 | O(n²) | O(n²) |
| Time 常数 | 小 | 大 5-10× |
| Space (额外) | **O(1)** | **O(n²)** worst |
| Heavy duplicate input | 立刻跳 | 做完再扔，浪费 work |
| Interview signal | ✅ 掌握 pattern | ❌ 绕过 pattern |

### 🎯 A 级面试答案

> "Set 可以，但 space O(1) → O(n²)，heavy duplicate input 上做大量无用 work，且**绕过了 skip-duplicates pattern** —— 这个 pattern 扩展到 4Sum / 3Sum Closest 等家族题。所以**最优解还是 skip-duplicates**，set 只在快速 prototype 不在意 perf 时合适。"

**senior signal**：不只 "X 更好"，而是 "我知道两种方案，知道选哪个 + 为什么 + 什么场景反过来"。

## 🧠 Common Pitfalls

1. ❌ 忘 outer i 的 skip → e.g., `[-1,-1,-1,2]` 会出现两次 `[-1,-1,2]`
2. ❌ 忘 inner l 的 skip → e.g., `[-2,-2,0,0,2,2]` 出现两次 `[-2,0,2]`
3. ❌ `nums[l] == nums[l-1] and l < r` 顺序错 → 潜在 IndexError
4. ❌ 主语不清的 comment（如 "tool 不需要自己去找适用的文件"）→ 习惯写 unambiguous code
